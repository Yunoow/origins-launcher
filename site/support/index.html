Questions sur l'installation →
Le jeu ne se lance pas

Le launcher affiche maintenant pourquoi. Essaie Réessayer ; si ça bloque toujours, ouvre un ticket sur le Discord d'Origins avec une capture de ce message.

La connexion Microsoft ne marche pas

Il faut le compte Microsoft qui possède Minecraft : Java Edition. Ferme complètement le launcher, rouvre-le et reconnecte-toi.

Les mobs ont l'apparence d'animaux

Accepte les packs proposés à la connexion au serveur, puis active une fois le pack des modèles dans Options → Packs de ressources.
