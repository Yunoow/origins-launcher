Origins Launcher

A third-party launcher for Minecraft Java Edition on Windows, built to provide the Origins experience through a dedicated desktop application.

MICROSOFT SIGN-IN

Users authenticate with their own Microsoft account. Origins Launcher does not ask for or store Microsoft passwords.

LEGITIMATE OWNERSHIP

The launcher is intended for users who legitimately own Minecraft. It does not bypass authentication, entitlement, licensing, or server online-mode checks.

JAVA EDITION

Origins Launcher launches Minecraft Java Edition and uses the authenticated user's Minecraft profile for supported online play.

ABOUT THE PROJECT

Origins Launcher is an independent, third-party project and is not affiliated with, endorsed by, or sponsored by Microsoft or Mojang. Minecraft is a trademark of Microsoft.
